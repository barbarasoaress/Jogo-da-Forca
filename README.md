# 🪢 Jogo da Forca em Python

Jogo clássico da forca desenvolvido em **Python** para ser executado no terminal.

## 🚀 Tecnologia utilizada

- Python

## ✨ Funcionalidades

- Escolha aleatória de palavras
- Entrada de letras pelo jogador
- Controle de letras já utilizadas
- Atualização da palavra oculta a cada tentativa
- Limite de 6 tentativas incorretas
- Mensagens de vitória e derrota

## ▶️ Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Execute no terminal:

```bash
python index.py
```

## 📚 Objetivo do projeto

Projeto desenvolvido para praticar funções, listas, estruturas de repetição, condicionais, entrada de dados e uso do módulo `random` em Python.
